How it works

  1. The model asks. It gathers facts one question at a time and writes down which message each answer came from.
  2. The engine decides. policyengine-us 2.0.4 computes every amount from the statute; no model ever states a dollar figure.
  3. A human is interrupted only by a card. Everything else lands in the ledger with ten minutes to undo it.

Eligibility is computed with policyengine-us, licensed AGPL-3.0. Benefitline calls it as a separate program and shows the rule URL under every number.
